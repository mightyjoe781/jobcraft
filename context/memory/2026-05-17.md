## Key Decisions

- **`.tex` as canonical format** — PDFs always derived, always re-renderable
- **Celery fixed**: `-Q default` flag caused all tasks to queue silently; removed so worker listens to `celery` queue
- **SSE race condition fix**: when worker finishes before client subscribes, SSE endpoint checks `variant.pdf_path` and emits immediately
- **Celery DB fix**: `asyncio.run()` creates new event loop; `AsyncSessionLocal` pool connections from old loop caused `Future attached to a different loop`; fixed with `_make_session()` creating fresh engine per task
- **Cover letter DB fix**: `async with db.begin()` inside streaming generator used detached session; switched to fresh engine post-generation
- **date_trunc SQL fix**: SQLAlchemy parameterises date_trunc unit string; fixed with `literal_column("'week'")` and `sa_text("1")` for GROUP BY/ORDER BY
- **memsearch local provider**: uses sentence-transformers, no OpenAI API key; needs `KMP_DUPLICATE_LIB_OK=TRUE` on macOS
